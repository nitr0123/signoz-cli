# Security policy

## Supported versions

Only the latest release receives fixes. Upgrade with `signoz update --apply`.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on
https://github.com/nitr0123/signoz-cli/security/advisories/new

Do not open a public issue for security problems. Include the version
(`signoz --version`), the command involved, and a minimal reproduction.
You can expect an acknowledgement within a week.

`ADVERSARIAL_REVIEW.md` records the hardening reviews done so far and is a
good place to check whether an issue is already known.
